切网前保留这些恢复与退出步骤

切网后保留当前页面，不要刷新。以下文字无需网络即可阅读；退出或恢复不依赖继续在线向 Codex 求助。

  1. 准备：记录原 Wi-Fi、蜂窝／热点与其它网络设置，确认 iPad 原生 PadInk 及转发辅助程序已停用。Mac 记录探针 PID、端口和本页 runID；不卸载或清除 App 数据。
  2. 前正对照：保持已知可工作的同一局域网，在本页选择“前正对照”，完成至少三次不同 nonce 的有效回显。失败则停止 USB 判定。
  3. 隔离与普通线：由用户停用会掩盖路径的 Wi-Fi、蜂窝／热点和其它承载，再用普通数据线测试。选择“普通线”，每次插／拔后点击一次，最多三次插拔。接口名或插着线都不能独立证明路径。
  4. 后正对照：恢复先前记录的局域网设置，Mac 探针保持同一 PID、端口和 runID。选择“后正对照”，在有效 Mac 地址下完成至少三次新 nonce。不能恢复、进程重启或后对照失败时，本轮为证据不足。
  5. 退出：恢复原设置；在 Mac 终端先用 ps -p __PADINK_PID__ -o pid=,command= 核对该 PID 仍为本次 WebProbe，再运行 kill -INT __PADINK_PID__（也可在启动终端按 Control-C）。用 lsof -nP -a -p __PADINK_PID__ -iTCP:__PADINK_PORT__ -sTCP:LISTEN 核对无监听，再选“退出验收”发起一次新 nonce；此时应失败。PID 已退出则不再 kill；不要停止其它进程。

若 Mac 地址改变，需使用恢复后的有效地址并核对相同 runID；不得把新进程的成功接到旧进程的前正对照。新地址页面的本地历史不包含上一页记录，使用 nonce 与 Mac 控制台关联。

最终结果由前后对照、监听覆盖、人工隔离和端点／接口证据共同判断：PASS_IP_PATH、NOT_ESTABLISHED_ON_THIS_SETUP 或 INCONCLUSIVE。本页不自动给出这三种结论。
