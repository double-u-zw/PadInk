# PadInk 安装、升级与首次使用

PadInk 把 Mac 主屏显示到 iPad，让 Apple Pencil 和手指操作 Mac 应用。书写结果由 Mac 应用保存；PadInk 保存配对、设置和本机诊断。

## 1. 选择正确安装路径

| 使用者 | Mac | iPad |
|---|---|---|
| 当前公开测试版（0.3.0 Beta 1 / build 5） | [发布页](https://github.com/double-u-zw/PadInk/releases)的未公证 Mac 测试 DMG，与官方 AltServer 1.8.1 | 官方 AltStore Classic 安装 PadInk IPA，并管理续签 |
| 正式 RC 测试者（后续） | 发布页下载 Developer ID 签名、Apple 公证并附带公证票据的 PadInk 应用 ZIP | 使用发布页的 TestFlight 邀请；在 iPad 的 TestFlight 中安装 |
| 稳定版普通使用者 | 同一正式发布者提供的公证包 | App Store 安装与更新 |
| 开发者 / 现有免费签名测试者 | 自己从源码构建 | Xcode 与自己的团队签名，见[开发者指南](https://github.com/double-u-zw/PadInk) |

**本轮提供 AltStore 公开测试材料，尚无公证包或 TestFlight 邀请。** 下载入口见 [GitHub Release](https://github.com/double-u-zw/PadInk/releases)，问题反馈见 [Issues](https://github.com/double-u-zw/PadInk/issues)。发布仓库目前承载安装包与使用文档，自动生成的 Source code 附件仅包含这些文档；完整产品源码由维护者私下保留。 首次安装请直接使用[简明安装说明](AltStore安装说明.txt)，完成后记录[真人验收清单](试用验收清单.txt)。当前候选包的实际安装、文稿与升级验收尚待完成。 源码 ZIP 和未签名构建预览不能直接安装；本项目为 AltStore 构建的 IPA 需由官方 AltStore 签名后安装。发布准备与维护者步骤见[RC 流程](https://github.com/double-u-zw/PadInk/releases)。正式路径中使用者无需 Xcode、Apple Developer Program 或每周重签；TestFlight 每个构建最多测试 90 天，需要维护者持续提供新构建，见 [Apple 说明](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/)。

准备 Mac、iPad、Apple Pencil 和能传数据的 USB 线。Wi-Fi 要在同一局域网并允许本地网络权限。工程最低版本为 macOS 14 / iPadOS 17；当前真机覆盖与应用边界见[支持矩阵](SUPPORT_MATRIX.md)。

## 免费安装与续签：AltStore Classic

先按简明说明安装 Mac 的 `PadInk-Mac-Test.dmg`；它是未公证测试包，首次打开按系统提示处理。同一 Mac 已有原开发版时，先联系维护者确认身份与保留方式，不直接覆盖。

1. 从 [AltStore 官网](https://altstore.io/)下载稳定版 AltServer，放入 Mac“应用程序”并打开；macOS 27 使用 **1.8.1 或更新的稳定版**，旧首页链接可能仍返回 1.8，可在 AltServer 菜单检查更新。[官方 1.8.1 公告](https://bsky.app/profile/altstore.io/post/3mvqfomflhc26)说明已修复 machineID 错误。连接并解锁现有 iPad，按系统提示信任电脑、启用开发者模式。按[官方 Mac 安装指南](https://faq.altstore.io/altstore-classic/how-to-install-altstore-macos)安装 AltStore Classic；账号密码和双重认证只在官方窗口输入。
2. 已有 Xcode 开发签名的用户先确认账号证书：AltServer 为免费团队创建签名证书时可能撤销原证书，使已有开发 App 无法启动。优先使用未用于开发签名的免费账号；不要直接用正式 PadInk 的签名账号尝试。无需另一台 iPad。
3. 将维护者提供的 `PadInk-AltStore.ipa` 传到 iPad“文件”，在 AltStore“ My Apps”点“+”选择 IPA。当前包显示为 **PadInk AltStore**，独立 Bundle ID 为 `dev.padink.altstore.ipad`（AltStore 签名后可能追加团队后缀），不接管正式 PadInk。首次配对只确认正在使用的 Mac。
4. 在 AltStore 设置启用 Background Refresh，Mac AltServer 保持运行；可在 Mac“系统设置 › 通用 › 登录项与扩展”将 `/Applications/AltServer.app` 加入“登录时打开”。在 My Apps 的 Refresh All 手动验证续签，再打开同一 App 检查设置、配对和实际画面/输入。不要使用 Deactivate、卸载或换账号来处理失败。

免费账号通常最多同时安装 3 个侧载 App（含 AltStore），签名约 7 天。后台刷新由 iPadOS 调度，需要 AltServer 可达；插线本身不保证立刻刷新。Mac VPN 保持开启，若发现连接问题，检查 USB、设备解锁与 AltServer 发现链路，不要求关闭 VPN。[官方刷新说明](https://faq.altstore.io/altstore-classic/your-altstore)

已在 iPadOS 27.0.1 通过官方 AltServer 1.8.1 / AltStore Classic 2.3 安装独立版 PadInk，签名有效期确认为 7 天；Refresh All 原位续签后，到期时间延后，Bundle ID、Team、证书和源码摘要不变，测试文件内容一致、手指操作设置保留，无需重配对，USB 画面与 Pencil 正常。Mac VPN 全程保持连接，AltServer 已加入登录启动项。后台自动刷新、过期恢复和纯无 Xcode Mac 环境尚未实测，不能宣称“插线必定自动续签”；官方后台刷新也未验证能避让正在书写的会话。现有 Xcode 安装的正式 PadInk 保留原安装与更新方式，不通过同名 IPA 强行迁移。

## 2. 普通使用者安装（正式包可用后）

1. Mac 下载该次发布的 PadInk 应用 ZIP，解压，将 **PadInk.app** 放到“应用程序”，然后打开。保留发布页与安装包版本，保持 Gatekeeper 安全检查；公证票据已经附在 App 中，可供系统验证。遇到开发者身份无法验证或签名损坏时，重新从发布页下载并联系发布者，不关闭系统安全检查。
2. iPad 安装 Apple 的 TestFlight，打开该次发布的邀请链接并安装 PadInk；稳定版直接从 App Store 安装。TestFlight / App Store 安装无需开发者模式，也无需“信任开发者”。
3. 找到 Mac 菜单栏的笔形图标；iPad 打开 PadInk 并保持前台。下面的首次使用流程适用于所有安装渠道。

## 3. 首次运行：两端各做什么

| Mac | iPad |
|---|---|
| 打开 PadInk，点击菜单栏笔形图标；首次引导说明两端步骤 | 打开 PadInk，保持前台、屏幕解锁 |
| 按 PadInk 提示允许**屏幕录制**和**辅助功能**；按系统要求退出重开 | USB 插线并允许“信任此电脑”；首次确认 PadInk 配对 |
| 首次也确认 PadInk 配对，只允许正在使用的设备 | 等右上角显示 USB 和画面状态，再看到 Mac 画面 |
| 打开要操作的文稿，选择应用自己的笔或标注工具 | Pencil 书写；手指选工具，双指滚动或捏合 |

Mac 不需要主窗口。录屏授权后仍无画面时彻底退出重开 Mac PadInk；只关闭菜单不是退出。画面显示正常但不能输入时检查辅助功能授权。PowerPoint 缩放可能另询问“自动化”授权；拒绝时到系统设置的“隐私与安全性 › 自动化”调整，Pencil 书写不依赖这项权限。

先在 PowerPoint“绘图 › 笔”或 GoodNotes 笔工具写两笔，保存文稿，再确认结果。PadInk 不替你保存，也没有独立的 iPad 笔记本。

## 4. 连接、Wi-Fi 与恢复

Mac 面板和 iPad 右上角显示当前状态及 USB / Wi-Fi。连接建立与画面可以操作是两个步骤；“等待画面”先看 Mac 录屏提示，无需反复配对。

- 首次推荐 USB 配对。以后打开两端可自动连接；同一局域网、本地网络权限允许时，已配对设备也可用 Wi-Fi。
- 不插线配对：iPad“设置 › 连接与设备”中点“配对 Wi-Fi”；Mac 在“设置 › Wi-Fi 连接”中找到你的 iPad 并点“配对”。两端六位短码完全一致才允许。窗口约 120 秒，过期可重开。
- USB 优先：Wi-Fi 在线插线切到 USB；拔线尝试恢复 Wi-Fi。切换结束当前手势，恢复后重新落笔；断线期间的输入不会补送。
- Wi-Fi 找不到时检查同一网络、本地网络授权和 iPad 前台。访客、公司或课堂网络可能禁止设备互连，先用 USB。
- 恢复中先检查线和网络，保持 iPad 前台；持续失败先导出诊断再重开两端。主动暂停后在 Mac 点“重新连接”。

只有需要更换可信设备或明确修复配对失败时才“忘记设备”。普通断线、无画面和正常更新不需要删除配对。

## 5. 应用与输入范围

配套 Ecru 支持 PDF 文稿书写、双指连续缩放与二维平移；需维护者确认带 bridge v1 的适配构建，本包不包含 Ecru。PowerPoint 在绘图中选笔后写入；GoodNotes 在激活的文稿内容区书写、普通滚动和连续捏合。Preview 使用 PDF 自己的标注工具，需在实际 PDF 验证保存。Safari / Chrome 支持浏览、点击、滚动与页面缩放，网页不会自动变成可保存的手写笔记。

工具、颜色和橡皮通过目标应用的界面选择；输入作用于 Mac 当前应用。捏合与“恢复应用默认缩放”依赖该应用公开能力及当前文稿焦点。菜单或弹窗中先回到文稿；仍不可用就用应用自己的缩放控件。更多边界见[支持矩阵](SUPPORT_MATRIX.md)。

## 6. 升级与版本核对

本轮 AltStore 候选更新：先保存文稿、结束书写并退出 Mac PadInk；用同一试用分发身份的新 Mac DMG 覆盖，在 AltStore 导入新的 IPA。保持原 Apple ID，不先删除 App；Refresh All 只续签当前内容。更新后检查设置、配对、权限和真实操作；未公证 Mac 测试包的 TCC / Keychain 延续尚待验收，若系统重新询问授权，记录结果。原开发版转入本轮试用属于身份变化，先联系维护者。

正式包可用后，正常升级时先保存文稿、退出 Mac PadInk，从同一发布者的新 ZIP 覆盖 `/Applications/PadInk.app`；iPad 在 TestFlight / App Store 更新。**保留 App 和配对，无需卸载、重签或复制钥匙串。** 同一发行团队、bundle ID 与存储格式是保留设置/信任的前提；首次正式签名升级仍需维护者真机确认。


从旧 `PadInk 0.3.app` 更新时，安装工具先安装并启动 `/Applications/PadInk.app`，保留旧 App 与回滚副本；确认设置和已配对设备仍在后，才清除旧显示名副本。不要提前删除旧 App。
优先使用同一次发布的 Mac 与 iPad。设置/关于里可以找到版本、build、渠道和源码标识；连接兼容性由协议范围决定，版本号相同本身不保证兼容。出现版本不兼容时更新两端到发布说明列出的组合，并导出诊断；不要靠反复配对解决。

从旧免费签名测试包转为正式包属于**身份变化**：可能显示两个 App，旧设置与信任不保证迁移。先保留旧 App 与文稿，在正式版本重新授权、配对，确认可用后再处理旧副本。正常升级不要求删除 App。

首次 RC 不承诺跨版本降级。需要回退时联系维护者，由维护者确认两端协议和存储格式的兼容组合；iPad App Store 不提供任意旧版安装，TestFlight 只能选仍有效且维护者保留的构建。免费签名到期的源码操作见[开发者指南](https://github.com/double-u-zw/PadInk)。

## 7. 出问题时：诊断与退出报告

| 问题 | 下一步 |
|---|---|
| Mac 没有菜单栏图标 | 从“应用程序”打开 PadInk；检查是否开了旧免费测试副本 |
| 等待连接 | 两端打开；USB 检查数据线、解锁与信任；Wi-Fi 检查同一网络与本地网络授权 |
| 已连接，等待画面 / 录屏失败 | 看 Mac 录屏权限提示；授权后按系统要求退出重开 |
| 画面正常，不能输入 | 检查辅助功能、目标文稿焦点及笔工具；仅手指失效时检查手指输入设置 |
| 配对未完成 | 核对短码，重新开启配对；不允许不一致的短码 |
| 恢复 / 解码失败 | 保持 iPad 前台；持续失败先导出诊断再重开 |
| TestFlight 构建过期 | 在 TestFlight 更新；无新构建时联系发布者，不删除 App 或改走免费重签 |
| 两端版本不兼容 | 更新为同次发布列出的组合 |

Mac 打开 PadInk 主窗口的“诊断”，点“导出并在 Finder 显示”，取出“文稿 / PadInk 诊断”里的 JSON；iPad 打开“设置 › 诊断”，点“生成 iPad 诊断”，生成后用“分享诊断文件”保存到文件或 AirDrop。提供两端 JSON，附上**应用、USB/Wi-Fi、最后操作与发生时间**。Release 诊断没有画面、文稿名、窗口标题、完整文件路径或逐笔坐标；分享由你选择。[隐私说明](PRIVACY.md)

如果 App 突然退出，重开后可以导出诊断，但它不代替系统崩溃报告。Mac 在“控制台”App 的“崩溃报告”找到对应 PadInk `.ips`；iPad 在“设置 › 隐私与安全性 › 分析与改进 › 分析数据”查找 PadInk 对应时间的报告并分享。TestFlight 也可提交反馈。没有对应报告时直接提供时间和重开的诊断，无需猜测是 crash、系统结束还是内存回收。系统报告可能带设备或进程信息，发送前可查看。[Apple 控制台报告说明](https://support.apple.com/guide/console/cnsl664be99a/mac) · [Apple 获取 crash 报告说明](https://developer.apple.com/documentation/xcode/acquiring-crash-reports-and-diagnostic-logs)

## 8. 最短真实任务验收

本轮按[真人验收清单](试用验收清单.txt)先完成 USB 首次安装与真实文稿，再补 30–60 分钟使用、Wi-Fi、续签与升级。已有旧包记录不能代替当前候选包验收。

正式发行路径可先完成约 10–15 分钟的检查：冷启动与授权；USB / Wi-Fi 配对；一份 PowerPoint 或 GoodNotes 文稿的书写、滚动、缩放、保存重开；Wi-Fi 插拔 USB；双端导出诊断。升级另外检查原配对和设置是否保留。

第二位独立使用者暂缺不阻塞 RC 准备；首次正式签名包仍必须在现有真机验收，下载后的 Gatekeeper 启动和 TestFlight 安装也不能由无签名 build 代替。
