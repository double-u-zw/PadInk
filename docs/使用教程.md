# PadInk 使用教程

本教程适用于 **0.3.0 Beta 3 / build 11**。安装先看[安装步骤](AltStore安装说明.txt)。PadInk 将 Mac 主屏显示到 iPad，让 Apple Pencil 和手指操作当前 Mac 应用。文稿仍由 Mac 应用管理和保存。

## 第一次连上画面

1. 在 Mac 的“应用程序”打开 **PadInk**，点击菜单栏笔形图标查看连接状态。两端都使用本次发布的 PadInk。
2. 在 iPad 打开 **PadInk**，保持前台和解锁。用能传数据的 USB 线连接 Mac，允许“信任此电脑”和本地网络访问。
3. 按两端提示确认自己的设备配对。等 iPad 显示 USB 连接和 Mac 画面；连接建立后，画面还可能需要短暂准备。
4. 没有画面：在 Mac 的“系统设置 → 隐私与安全性”检查屏幕录制权限，按系统要求退出并重开 PadInk。能看不能写：检查辅助功能权限。

首次连接成功后，正常断线无需删除配对。

## 完成一份真实文稿

1. 在 Mac 打开一份测试文稿，让目标应用处于前台。首次可选你已经安装的 PowerPoint 或 GoodNotes。
2. **先在目标应用选择笔工具**：PowerPoint 进入“绘图”并选择笔；GoodNotes 进入文稿并选择笔。PadInk 不会自动替你选择绘图模式。
3. 用 Apple Pencil 在 iPad 画面上写长短笔。先在页面四角和中间各写一笔，确认位置正确。
4. 用手指点目标应用的颜色、笔或橡皮工具，再用 Pencil 写字或擦除。若手指不能操作，检查 PadInk 设置中的手指输入开关。
5. 用双指滚动页面、捏合缩放；回到笔工具继续写。缩放支持由应用和文稿焦点决定，见下表。
6. **在 Mac 应用中保存**，关闭文稿，再重新打开，确认书写和擦除结果。重要文稿先自行备份；建议先用测试副本熟悉 Beta。

| 应用 | 操作与限制 |
|---|---|
| PowerPoint | 先选“绘图 → 笔”，再写擦；缩放可能需要允许 macOS“自动化”权限。 |
| GoodNotes for Mac | 在激活的文稿内容区写擦、滚动、连续捏合；菜单、弹窗或文字编辑状态下先回到文稿。 |
| Preview | 先选择 PDF 既有标注工具；具体 PDF 的书写和保存仍需实际验证。 |
| Safari / Chrome | 点按、浏览、滚动和页面缩放；网页不会自动成为可保存的手写笔记。 |
| 配套 Ecru | 指定适配构建支持 PDF 书写、连续缩放和二维平移；本安装包不包含 Ecru，先向维护者确认版本。 |

输入会操作 **Mac 当前前台应用**。切换应用后检查目标与工具；打开菜单、弹窗或切换文稿时先抬笔。缩放不可用时可使用目标应用自己的缩放控件。

## USB、Wi-Fi 与恢复

首次推荐 USB。之后同一局域网且本地网络权限已允许时，可尝试 Wi-Fi；本次包的完整 Wi-Fi 验收仍待完成。

- 已配对设备：打开两端，保持 iPad 前台，可尝试 Wi-Fi 自动连接。
- Wi-Fi 首次配对：iPad“设置 → 连接与设备 → 配对 Wi-Fi”，Mac“设置 → Wi-Fi 连接”中选择 iPad。只在两端六位短码一致时确认。
- USB 优先；Wi-Fi 使用时插线会尝试切到 USB，拔线会尝试恢复 Wi-Fi。切换会结束当前手势，恢复后重新落笔；断线输入不会补送。
- 访客、公司或课堂网络可能限制设备互连。失败时先使用 USB，不需要为排查关闭 VPN。
- 后台、锁屏或休眠后，先解锁 iPad并回到 PadInk，等待画面恢复。持续失败时先导出诊断，再重开两端。

## 续签与升级

iPad 免费 AltStore 签名约 7 天有效。Mac AltServer 保持运行、在安装及续签时能找到 iPad；在 AltStore Settings 开启 Background Refresh，并允许 iPad 系统的后台 App 刷新。自动刷新由 iPadOS 调度，不能保证固定时刻完成。[官方说明](https://faq.altstore.io/altstore-classic/your-altstore)

每隔几天检查 AltStore My Apps 的有效期。临近到期时先保存文稿、结束书写，连接 USB 并解锁，在 AltStore 点 **Refresh All**；成功后重开 PadInk检查连接。不要等到重要任务当天才续签。

**Refresh All 只续签已有代码，不会下载新版。** 收到新版本时：保存文稿、退出 Mac PadInk，从发布页下载对应芯片包并覆盖同身份 App，再在 AltStore 用“+”导入新 IPA。保持原 Apple ID 和已有 App，检查版本、设置、配对和实际操作。未公证 Mac 包更新可能再次询问权限；当前公开包的覆盖升级尚待验收。

AltStore 过期时按[官方 AltServer 帮助](https://faq.altstore.io/altstore-classic/altserver)原位安装恢复；PadInk 到期或刷新报错时保留 App 和错误信息，联系维护者。切换账号、卸载和重新配对不是常规续签步骤。

## 常见问题与反馈

| 现象 | 先检查 |
|---|---|
| Mac 没有菜单栏图标 | 从“应用程序”打开 PadInk，确认没有误开旧副本。 |
| 等待连接 | 双端 PadInk、USB 数据线、iPad 解锁和设备信任；Wi-Fi 另查同一网络和本地网络授权。 |
| 已连接但没有画面 | Mac 屏幕录制权限；授权后彻底退出再打开 Mac PadInk。 |
| 有画面但不能写 | Mac 辅助功能权限、前台目标文稿与笔工具。 |
| 只有滚动/缩放不工作 | 手指输入开关、目标应用能力与文稿焦点；退出菜单和弹窗后重试。 |
| 两端版本不兼容 | 从同一次发布更新 Mac 和 iPad，保留原 App 与配对。 |
| AltStore 找不到 AltServer | Mac AltServer 正在运行、USB 连接及解锁；Wi-Fi 发现另需 Finder 中启用“通过 Wi-Fi 显示此 iPad”。 |

Mac：PadInk 主窗口 → 诊断 → 导出并在 Finder 显示。iPad：设置 → 诊断 → 生成 iPad 诊断 → 分享诊断文件。

在 [GitHub Issues](https://github.com/double-u-zw/PadInk/issues)提供设备/系统、双端 build、目标应用版本、USB/Wi-Fi、时间与复现步骤。逐项填写[真人验收清单](试用验收清单.txt)。诊断是否分享由你决定；公开反馈不附个人文稿、账号密码、验证码、证书或钥匙串。
